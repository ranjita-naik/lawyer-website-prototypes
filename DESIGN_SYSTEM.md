# DESIGN_SYSTEM.md

# Design Philosophy

The goal is not to create the loudest website.

The goal is to create a website that people enjoy spending time on.

Every design decision should improve clarity, elegance, and trust.

When in doubt, choose restraint over decoration.

---

# Overall Feeling

The website should feel:

- elegant
- calm
- welcoming
- premium
- thoughtful
- modern
- timeless

Avoid designs that feel:

- loud
- flashy
- cluttered
- overwhelming
- chaotic
- gimmicky
- trendy for the sake of trends

A visitor should feel relaxed rather than visually overwhelmed.

---

# Color Philosophy

Prefer soft, sophisticated color palettes.

Colors should support the content rather than compete for attention.

Avoid:

- neon colors
- oversaturated gradients
- harsh reds
- extremely bright blues
- overly vibrant greens
- high-contrast color combinations that strain the eyes

Favor:

- muted tones
- natural colors
- warm neutrals
- subtle earth tones
- elegant blues
- soft greens
- gentle accent colors

Accent colors should be used intentionally and sparingly.

Large sections should feel comfortable to read for long periods.

---

# Visual Hierarchy

Whitespace is a feature.

Never try to fill every empty area.

Allow content room to breathe.

A clean layout is usually better than a busy one.

Users should immediately know:

1. where to look
2. what is important
3. what action to take

---

# Simplicity

Every element should have a purpose.

If removing something improves the design, remove it.

Avoid unnecessary:

- icons
- animations
- borders
- decorations
- badges
- labels

Less is often more.

---

# Typography

Typography should communicate confidence.

Prefer:

- generous spacing
- readable line lengths
- strong hierarchy
- consistent rhythm

Headings should feel refined rather than oversized.

Body text should remain effortless to read.

---

# Motion

Animation should feel natural.

Motion should guide attention, never distract from it.

Prefer:

- subtle fades
- gentle transforms
- smooth easing

Avoid:

- bouncing
- spinning
- excessive parallax
- constant movement
- attention-seeking animations

The interface should feel calm.

---

# Depth

Depth should come from:

- spacing
- layering
- shadows
- lighting

Not from excessive borders or visual effects.

Shadows should be soft and subtle.

---

# Components

Every component should appear intentional.

Buttons should feel tactile.

Cards should have breathing room.

Forms should feel approachable.

Navigation should disappear into the experience rather than dominate it.

---

# Imagery

Images should complement the design.

Avoid overly saturated stock photography.

Prefer imagery that feels:

- authentic
- warm
- high quality
- emotionally genuine

Images should reinforce the story instead of distracting from it.

---

# Accessibility

Beautiful design should never sacrifice usability.

Always maintain:

- readable contrast
- comfortable font sizes
- keyboard accessibility
- visible focus states

Accessibility is part of elegance.

---

# Final Test

Before considering a design complete, ask:

- Does this feel calming?
- Does this feel elegant?
- Is anything visually distracting?
- Can I simplify this further?
- Is the content still the hero?
- Would someone enjoy looking at this for several minutes?

If any answer is "no", continue refining.
