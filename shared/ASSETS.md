composition. Every one of them should be replaced with the client's own photography and
imagery before the site goes live. File names below match `shared/images/*.jpg`.

## Explicitly avoided

Per the design brief: no gavels, no scales-of-justice iconography, no staged handshakes, no
triumphant courtroom imagery, no visibly AI-generated portraits, no overly saturated or
"touristy" architecture shots, no dark-navy/gold cliché legal-website aesthetic.

## Replacing these later

Each prototype's `NOTES.md` lists exactly which of these files it uses and where. To swap in the
client's real photography, replace the file at the same path/filename (or update the `src`
attribute — every image tag includes a short HTML comment noting it is a placeholder).
