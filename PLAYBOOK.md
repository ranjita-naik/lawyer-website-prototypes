# Website Design Playbook

A collection of proven techniques for building high-quality websites with Claude Code.

---

# 1. Frontend Design Skill

Always invoke the frontend-design skill before writing frontend code.

It consistently improves:

- typography
- spacing
- hierarchy
- color palette
- polish

---

# 2. Screenshot Iteration

Visual quality improves dramatically when designs are reviewed iteratively.

Workflow:

Build

↓

Run locally

↓

Capture screenshot

↓

Compare against goal

↓

Identify differences

↓

Refine

↓

Repeat

Skip screenshot comparisons for:

- animated backgrounds
- particles
- continuously moving components

---

# 3. Use Real Websites as References

Instead of describing a layout:

- capture a full-page screenshot
- inspect important CSS
- recreate the layout
- replace:
  - branding
  - copy
  - imagery
  - colors

This is usually faster than starting from scratch.

---

# 4. Component Libraries

Useful sources:

- 21st.dev
- Magic UI
- Aceternity UI
- shadcn/ui

Great for:

- hero sections
- pricing cards
- testimonials
- animations
- backgrounds
- buttons

Use components selectively to maintain a consistent design language.

---

# 5. Design Philosophy

Aim for:

- premium typography
- restrained color palette
- generous whitespace
- subtle motion
- clear hierarchy
- visual rhythm
- intentional depth

Avoid:

- generic Tailwind aesthetics
- repetitive cards
- excessive gradients
- random spacing
- flat interfaces

---

# 6. Visual Polish Checklist

Before finishing:

□ spacing is consistent

□ typography hierarchy is clear

□ colors are consistent

□ hover states exist

□ focus states exist

□ mobile layout works

□ tablet layout works

□ desktop layout works

□ no overflow

□ no placeholder text

□ accessibility checked

□ images optimized

---

# 7. Accessibility

Always verify:

- sufficient color contrast
- keyboard navigation
- visible focus indicators
- semantic HTML
- descriptive alt text
- ARIA labels where appropriate

---

# 8. Performance

Prefer:

- lazy-loaded images
- optimized SVGs
- minimal JavaScript
- responsive images
- efficient animations
- reduced layout shift

---

# 9. SEO Defaults

Include:

- page title
- meta description
- Open Graph tags
- semantic heading structure
- descriptive URLs when applicable
